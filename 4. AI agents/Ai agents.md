# AI Agents

## 1. What is an AI Agent?

An **AI agent** is a software application powered by **Generative AI** that can:

-   🧠 Reason and understand natural language
-   🛠️ Use tools to perform tasks
-   🌍 Respond to changing/contextual conditions
-   ⚡ Take appropriate actions automatically

> **Simple idea:** An AI agent doesn't just **answer** : it can **reason, use tools, and take action**.

---

## 2. Components of an AI Agent

An AI agent has **3 key components**:

### 1\. Large Language Model (LLM)

The **brain of the agent**.

It provides:

-   Language understanding
-   Reasoning
-   Generative AI capabilities

---

### 2\. Instructions

A **system prompt** that defines:

-   The agent's role
-   Its behavior
-   How it should operate

> **Think of Instructions as the agent's job description.**

---

### 3\. Tools

Tools allow the agent to **interact with the world** and perform tasks.

There are two main types:

#### 📚 Knowledge Tools

Provide access to information.

Examples:

-   Search engines
-   Databases

#### ⚡ Action Tools

Allow the agent to perform actions.

Examples:

-   Send emails
-   Update calendars
-   Control devices

## 3. How an AI Agent Works

LLM + Instructions + Tools

            ↓

       AI Agent

            ↓

   Reason → Use Tools → Act

---

# 🤝 Multi-Agent Systems

A **multi-agent system** contains multiple AI agents that **collaborate**.

Instead of one agent doing everything, each agent can have a **specialized role**.

### Example

### Example

Agent 1 → Gather Data

              ↓

Agent 2 → Analyze Data

              ↓

Agent 3 → Take Action

              ↓

        Final Outcome

Each agent focuses on a specific task, similar to how members of a human team have different responsibilities.

Agents communicate with one another through **prompts**, using generative AI to determine:

-   What tasks need to be completed
-   Which agent should complete each task
